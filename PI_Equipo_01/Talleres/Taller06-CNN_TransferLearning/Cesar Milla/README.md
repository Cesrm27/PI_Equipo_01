# CNN y Transfer Learning con RetinaMNIST

En este taller se desarrolló un modelo de clasificación de imágenes médicas utilizando el dataset **RetinaMNIST**. Se implementó una CNN desde cero y Transfer Learning con ResNet18 para clasificar cinco grados presentes en imágenes de fondo de ojo.

Se evaluó el modelo mediante Accuracy, ROC-AUC, Kappa cuadrático, matriz de confusión y curvas ROC. Además, se experimentó con Batch Normalization, Dropout, Data Augmentation, Learning Rate Scheduler, Grad-CAM y calibración de probabilidades mediante Temperature Scaling.

El taller permitió comparar diferentes estrategias para mejorar el entrenamiento, evaluación e interpretabilidad de modelos de Deep Learning aplicados a imágenes médicas.
